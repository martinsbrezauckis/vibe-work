# Public documentation

Reference material for Vibe Work: the Debug API, handbook page format, browser pools, the shared UI vocabulary and
how to verify a release's checksums and signatures. [Browser Control setup and permissions](BROWSER_CONTROL.md)
describes Your Chrome, Your Edge, Your Safari and Your Firefox, the agent control frame with Pause, and the local
network question in the built-in browser.
These documents describe the interfaces used by the app, its bundled tools and external clients.

[Network proxies](NETWORK_PROXIES.md) describes optional proxy support and Linux setup.
