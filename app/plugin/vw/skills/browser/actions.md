# Browser action arguments

`browser_act`: `navigate {url}`, `list_tabs`, `close_tab {tab: id}`, `back`, `forward`, `reload`, `click {ref}` or `{x, y, ref?}` (viewport CSS pixels), `drag {ref, to}`, `type {ref, text, submit?}` (replaces text; submit presses Enter), `select {ref, value}`, `check {ref, checked}`, `press {key, ref?}`, `scroll {ref | direction}`, `hover {ref}`, `wait {text | ref | load, timeoutMs}`, `upload {ref, paths}` (files from this chat's folders; file pickers never open for you). Refs come from the latest `browser_read`; stale refs are refused. `list_tabs` gives `tabs` (id/site/owner/active/suspended; title/URL under `untrustedPageContent.tabs`). If shortened, continue with `browser_act({action: "list_tabs", tab: result.nextTab})`.
Native date fields take `YYYY-MM-DD`; text datepickers use the page's displayed format.

Everyday actions use the same names as Your Chrome, with arguments directly in `browser_act`:

- `page.dialogs` reads the held native alert, confirm, prompt, leave-page or HTTP sign-in dialog, even while page JavaScript is blocked. Answer its exact `dialogId` with `page.dialog.accept`, `page.dialog.dismiss`, or `page.dialog.prompt {text}`. A click or navigation that opens a dialog returns that dialog; answer it and read the result before repeating the input. Stop dismisses held dialogs. Reading and dismissing run in Ask; accepting a dialog and entering prompt text ask.
- `auth.basic {url, login, dialogId?}` answers HTTP Basic sign-in using a saved vault login name or id, with a browser approval card below Full access and the existing separate vault approval. It checks the native challenge's origin and reports whether the checked site loaded; credentials never appear in the tool. Read `page.dialogs` after a refusal. If the login is missing, ask the person to save or choose it in the vault. Never supply credentials as text or URL arguments.
- `page.double_click`, `page.right_click`, `page.middle_click`, and `page.triple_click` take `ref` or viewport `x, y` like `click`. `click` and all variants accept `modifiers: ["Alt", "Control", "Meta", "Shift"]` (choose the keys needed). These use checked native input; a failure after input says it may have acted and must not be repeated blindly.
- `files.download {url}` starts an HTTP(S) transfer using this page's profile cookies and returns `downloadId`. `files.wait_download {downloadId?, timeoutMs?}` waits at most 20 seconds; `timedOut` means unfinished. Omit the id only when this chat has exactly one download. Click receipts include newly observed `untrustedPageContent.downloads` with IDs. `files.list_downloads` lists this chat's recent downloads. Completed files are saved automatically to the chat's `downloads/` folder; `files.save_download {downloadId}` returns that artifact's path. A failed/interrupted download has no complete artifact. Wait before using a file. Ask: ordinary GET downloads need no approval; saving with `files.save_download` asks. Listing and waiting run.
- `window.open {url?}` creates an independent window with one new web page for this chat; an omitted URL opens a blank page. The receipt has `windowId` and `tab`. `list_tabs` includes window IDs. `window.focus {windowId}` brings that window forward and selects its page for the agent; `window.close {windowId}` closes it and its page. Window actions run in Ask, retain Stop and ownership checks, and never target another chat. Pass `tab` to ordinary page actions. Windows remain live under the browser engine limit; close one to free a slot.
- `capture.screenshot {ref? | clip?: {x, y, width, height}}` returns a PNG of one visible element or a viewport rectangle in CSS pixels. Omit both for the viewport. Scroll an offscreen element into view first. The usual vault screenshot restrictions apply.
- `cookies.metadata {names?}` lists current-site cookie attributes; `cookies.read {names?}` includes values and HttpOnly cookies. `cookies.change {operation: "set" | "remove" | "clear", name?, value?, path?, secure?, httpOnly?, sameSite?}` changes this site only. `set` needs name/value; `remove` needs name; path defaults to `/`.
- `storage.metadata {area: "local" | "session"}` lists keys. `storage.read {area, keys}` returns values or null. `storage.change {area, operation: "set" | "remove" | "clear", key?, value?}` changes the selected area; set needs key/value, remove needs key.
- `clipboard.read` and `clipboard.write {text}` transfer plain text for page work, at most 65536 UTF-8 bytes. Empty text clears it. Read reports `truncated` if capped. A live vault copy cannot be read.
