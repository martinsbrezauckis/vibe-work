# Your Firefox: details

Adds to [actions.md](actions.md) (support table, shared contracts) for Vibe Work's own Firefox window (profileId `firefox:agent`, or `firefox`).

Your Firefox is Vibe Work's own Firefox window: the user opens it with Settings > Browser > Your Firefox > Open window, and the agent works only in that window. If it is closed or not connected, ask the user to open it there. The window closes when Vibe Work quits. If Open window fails, ask the user to close the old Firefox window and open it again. Each Open window starts with an empty Firefox profile: no site stays signed in from an earlier window, so sign in again with a vault login or hand the step to the user.

The user's Firefox add-on only sends pages, links, images or selected text they share with **Ask Vibe Work**; it never hands over their tabs. Agent actions use Vibe Work's own window.

| Topic | Firefox behaviour |
|---|---|
| Frames | Frame refs and `frameId` reach ordinary web frames. Sandboxed, `data:` and other opaque frames are refused with a reason; open their content in an owned tab instead |
| Popups | Click/key receipts report loaded popups as effect:new_tab with tab IDs, keeping the original target; opened-then-closed before load = effect:popup_closed; unrelated tabs are not claimed. Confirmed loaded popups are owned by this chat; inspect the returned tab ID before acting in one |
| Ref input | Ref clicks, typing, selection, pointer and focus actions wait ≤2 s for the same node to be visible, uncovered, enabled and stable. Stop, detachment or document change ends the wait; timeout sends no input. Coordinate-only actions check immediately |
| `page.read {selector:{kind,value,index?}}` | kind css/xpath/alt/title/testId, zero-based index; `selectorCount` counts before indexing/paging; CSS/attribute selectors include observed closed shadow roots; XPath follows document semantics; the selected frame bounds the search; unreadable frames and scan limits are in coverage |
| `page.select {ref,values:[...]}` | Sets the complete enabled option set of a native multiple select; `[]` clears; readback: actual values, `trustedEvents:false`. On macOS a checked DOM route with synthetic input/change events; `page.click` with Control uses the context-menu button |
| Events and reads | Other native pointer/key input is browser-trusted; focus/blur/insert and DOM setters identify synthetic events. Reads include rich-editor refs, ARIA options, validation messages, image/reset input names. Submission receipts distinguish validation, page handling and navigation; they do not establish server acceptance |
| `page.drag` | Source ref or x/y, `path:[{x,y,durationMs?}]`, optional holdMs, button; top-frame viewport CSS px. Limits: 32 points, 250 ms per segment (default 50), 2000 ms hold, 4000 ms total; `path:[]` + holdMs = one hold/release. Verifies native path and release; no held state survives between calls. Stop releases the exact operation's input; native release can activate a click, so an interrupted result is unknown. HTML drag-data sources are unavailable |
| `window.focus` | Activates the one visible tab in the owned window and reads back focus. If the selected tab cannot be identified while hidden/minimized, it refuses without selecting another tab |
| `window.close` | Same contract as in actions.md; closing the last owned window leaves a separate neutral window for the connection. Network-idle waits are unavailable |
| `cookies.change {operation:"clear",tabId,origin}` | Requires Full access. Clears the host's cookies across all paths in the tab's storage partition (HttpOnly and parent-domain included; parent-domain cookies are shared by matching subdomains) and reads the remaining count back. Unrelated hosts remain untouched. Counts contain no cookie values. Unsupported browsers do not acquire cookie clearing from a storage-clear request |
| Chats | Separate windows and refs per chat; a condition wait yields to other chats; handover and Stop release only their own chat. A question to the user holds agent actions until answered or a new message from the user arrives. Input marks expire and are omitted from reads and captures. Changed refs, documents and controller ownership return a reason and recovery instruction; page changes do not identify who caused them |
